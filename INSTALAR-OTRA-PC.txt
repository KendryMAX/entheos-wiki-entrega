============================================================================
  ENTHEOS WIKI - INSTALAR Y ARRANCAR EN OTRA COMPUTADORA
============================================================================

Esta es la guia oficial de instalacion y arranque del proyecto Entheos Wiki.
Es para montar el proyecto desde cero en una PC nueva (Windows), a partir de
lo que esta subido a GitHub.

Todo lo que hay que escribir va en PowerShell, salvo cuando se avise lo
contrario. No hace falta ser administrador mas que en dos pasos puntuales
(el archivo hosts y, si hace falta, instalar MySQL/Node).

Resumen: 9 pasos. Si algo falla, mirar el final (PROBLEMAS COMUNES).

CAMINO UNICO: los scripts .bat. Esa es la forma de instalar y arrancar el
proyecto en Windows:

  INSTALAR.bat   Se ejecuta UNA sola vez: instala las librerias, te pide la
                 contrasena de root de tu MySQL y crea el .env solo, agrega
                 el dominio entheoswiki.localhost al archivo hosts y arma la
                 base de datos (esquema + datos + las 3 cuentas del equipo).
  INICIAR.bat    Se ejecuta CADA VEZ para arrancar el proyecto.

Con esos scripts se saltean los pasos 4, 5, 6, 8 y 9 (los cubren). Abajo
estan los pasos detallados como referencia, para entender que hace cada parte
o para resolver problemas.

La pagina se abre en: http://entheoswiki.localhost


----------------------------------------------------------------------------
QUE SE NECESITA
----------------------------------------------------------------------------

- Windows 10/11
- Node.js 20 o superior
- MySQL 8 (o MariaDB compatible)
- Microsoft Edge (se usa para generar los PDF)
- Git (opcional, para clonar; tambien se puede copiar la carpeta a mano)


----------------------------------------------------------------------------
PASO 1 - INSTALAR NODE.JS
----------------------------------------------------------------------------

1. Descargar el instalador LTS desde https://nodejs.org (boton "LTS").
2. Instalarlo con las opciones por defecto.
3. Comprobar. Abrir PowerShell y escribir:

     node -v
     npm -v

   Debe mostrar una version (por ejemplo v20.x.x o superior).


----------------------------------------------------------------------------
PASO 2 - INSTALAR MYSQL
----------------------------------------------------------------------------

1. Descargar "MySQL Installer for Windows" desde https://dev.mysql.com/downloads/installer/
2. Instalar "MySQL Server" y, si se quiere, "MySQL Workbench".
3. Durante la instalacion elegir el tipo de autenticacion
   "Use Strong Password Encryption" y ANOTAR la contrasena del usuario root.
   Esa contrasena se usa en el paso 5.
4. Comprobar que el servicio quedo encendido. En PowerShell:

     Get-Service | Where-Object { $_.Name -like 'MySQL*' }

   Debe decir "Running". Si dice "Stopped":

     Start-Service MySQL96

   (cambiar MySQL96 por el nombre que haya aparecido arriba si es distinto)


----------------------------------------------------------------------------
PASO 3 - COPIAR EL PROYECTO
----------------------------------------------------------------------------

Opcion A, con Git (recomendado):

     git clone https://github.com/KendryMAX/entheos-wiki.git
     cd entheos-wiki

El repositorio es PRIVADO. Antes de clonar hay que estar agregado como
colaborador y aceptar la invitacion (llega al correo, o se acepta en
https://github.com/KendryMAX/entheos-wiki/invitations). Los colaboradores son
KendryMAX, AngelDanielZ4914 y adrianodev.

Opcion B, a mano: copiar la carpeta del proyecto a cualquier ubicacion.
Evitar rutas con caracteres raros; con espacios funciona (se usan comillas).

Adentro de la carpeta debe estar el archivo package.json.


----------------------------------------------------------------------------
PASO 4 - INSTALAR LAS LIBRERIAS DEL PROYECTO
----------------------------------------------------------------------------

Con PowerShell ubicado DENTRO de la carpeta del proyecto, escribir:

     npm install

Esto descarga todas las dependencias dentro de node_modules/ (esa carpeta no
viene en el repositorio, por eso hay que crearla en cada PC).


----------------------------------------------------------------------------
PASO 5 - CREAR EL ARCHIVO .env
----------------------------------------------------------------------------

El archivo .env guarda las contrasenas y NO viaja en el repositorio. Hay una
plantilla. Copiarla:

     Copy-Item .env.example .env

NOTA: si se ejecuto INSTALAR.bat, el .env ya se creo solo (con la contrasena
de root que escribiste y un secreto de sesion aleatorio) y no hace falta tocar
nada, salvo que el MySQL use otro usuario: en ese caso se edita BD_USUARIO y
BD_CONTRASENA.

Abrir el .env con un editor (Notepad, VS Code) y cambiar como minimo:

  - BD_USUARIO        usuario de MySQL (INSTALAR.bat deja root)
  - BD_CONTRASENA     contrasena de ese usuario (INSTALAR.bat deja la que
                      escribiste durante la instalacion)
  - SESION_SECRETO    valor aleatorio largo. Generarlo con:

        node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

  - GMAIL_USUARIO / GMAIL_CONTRASENA / GMAIL_DESDE
        correo y contrasena de aplicacion de Gmail (opcional: solo para el
        envio de correo; se puede dejar el ejemplo).

  - EDGE              ruta a msedge.exe. Normalmente ya viene bien:
        C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe

Los valores de HTTPS (HTTPS_PFX y HTTPS_CLAVE) son del paso 7. Si todavia no
se hace el paso 7, se pueden dejar como estan y el proyecto anda igual por
http://entheoswiki.localhost.

IMPORTANTE: el archivo .env nunca se sube al repositorio. Esta en .gitignore.


----------------------------------------------------------------------------
PASO 6 - CREAR EL USUARIO Y LA BASE DE DATOS
----------------------------------------------------------------------------

Con INSTALAR.bat, el .env ya tiene usuario root y la contrasena de la PC: una
MySQL root ya puede crear la base entheos sin crear otro usuario, y
INSTALAR.bat ya corre "npm run bd:crear". El bloque de abajo es solo de
referencia para quien quiera usar un usuario dedicado en lugar de root.

Para un usuario dedicado, abrir MySQL desde la consola como root (pedira la
contrasena del paso 2):

     mysql -u root -p

Adentro de MySQL, escribir estas tres lineas (cambiar la contrasena):

     CREATE USER 'entheos'@'localhost' IDENTIFIED BY 'LaClaveQueElijas123';
     GRANT ALL PRIVILEGES ON entheos.* TO 'entheos'@'localhost';
     FLUSH PRIVILEGES;

     exit

Esa contrasena es la que va en BD_CONTRASENA del .env (paso 5). El usuario
entheos tiene permiso para crear y manejar la base entheos.

Ahora, en PowerShell (dentro del proyecto) crear la base y cargar los datos:

     npm run bd:crear

Debe terminar mostrando un resumen con usuario, rol, categoria, articulo y
etiqueta. Eso crea las tablas Y las cuentas del equipo.

Si mas adelante hay que dejar la base como nueva, se usa:

     npm run bd:reiniciar

ATENCION: bd:reiniciar borra la base entheos y la vuelve a crear desde cero.


----------------------------------------------------------------------------
PASO 7 - (OPCIONAL) DIRECCION CON NOMBRE Y HTTPS
----------------------------------------------------------------------------

Por defecto el proyecto se abre en http://entheoswiki.localhost (INSTALAR.bat
agrega el dominio al archivo hosts de Windows). Este paso es opcional: solo
sirve para tener https://entheoswiki.localhost.

Hace falta lo mismo en dos partes:

  7.1  Dominio. INSTALAR.bat ya agrega la linea al archivo hosts cuando tiene
       permiso. A mano, abrir PowerShell COMO ADMINISTRADOR y agregar:

         Add-Content -LiteralPath "$env:SystemRoot\System32\drivers\etc\hosts" -Value "127.0.0.1 entheoswiki.localhost"
         ipconfig /flushdns

  7.2  Certificado. El proyecto trae un script que lo crea e instala, y que
       imprime la clave. En PowerShell (dentro del proyecto):

         powershell -ExecutionPolicy Bypass -File ".\servidor\herramientas\certificado.ps1"

       El script imprime dos lineas para pegar en el .env:

         HTTPS_PFX=certificados/entheoswiki.pfx
         HTTPS_CLAVE=<la clave que imprimio>

       Guardar el .env y seguir.

Si se saltea este paso, el proyecto arranca solo en http://entheoswiki.localhost.
Si se hace, arranca en los dos a la vez: HTTPS en el puerto 443 y HTTP en el 80.


----------------------------------------------------------------------------
PASO 8 - ARRANCAR
----------------------------------------------------------------------------

En PowerShell (dentro del proyecto):

     npm run dev

Debe verse algo asi:

     Base de datos conectada: entheos
     Entorno: desarrollo
     Entheos Wiki escuchando en http://localhost:80

La terminal queda ocupada: es normal, el servidor esta vivo. No cerrar esa
ventana. npm run dev usa nodemon, asi que si se guarda un cambio de codigo el
servidor se reinicia solo.

Para probar en produccion (sin recarga automatica):

     npm run iniciar

Para apagarlo: Ctrl + C en esa terminal.


----------------------------------------------------------------------------
PASO 9 - VER LA PAGINA Y PROBAR QUE ANDA
----------------------------------------------------------------------------

Abrir el navegador en:

     http://entheoswiki.localhost

(Si se hizo el paso 7, tambien https://entheoswiki.localhost. Si el puerto 80
esta ocupado, cambiar PUERTO en .env y abrir http://localhost:PUERTO)

Paginas utiles:

     /                 portada
     /articulos        listado de articulos
     /comunidad        chat y miembros de la comunidad
     /personajes       personajes
     /lugares          lugares
     /reportes         reportes en PDF
     /acceso           iniciar sesion
     /no-existe        pagina de error 404

Cuentas de prueba (creadas por bd:crear):

     Kendry   / Kendry123     Administrador
     Angel    / Angel123      Editor
     Adriano  / Adriano123    Lector

Cambiar estas contrasenas antes de entregar (ver COMANDOS UTILES).

Pruebas automaticas:

     npm run prueba

Debe terminar con "pass 10" y "fail 0".


----------------------------------------------------------------------------
COMANDOS UTILES
----------------------------------------------------------------------------

  npm install         Descarga las librerias
  npm run dev         Servidor con recarga automatica (nodemon)
  npm run iniciar     Servidor normal
  npm run prueba      Pruebas automaticas (deben dar 10/10)
  npm run bd:crear    Crea la base y carga esquema + datos
  npm run bd:reiniciar Borra la base y la recrea desde cero
  npm run admin       Alta de cuentas, cambio de contrasena y de rol
  npm run exportar    Exporta articulos y reportes a PDF
  npm run importar    Importa el vault de Obsidian (herramienta interna)
  npm run formato     Formatea el codigo con Prettier


----------------------------------------------------------------------------
PROBLEMAS COMUNES
----------------------------------------------------------------------------

"No se pudo conectar con MySQL"
  - MySQL no esta encendido. Revisar con Get-Service (paso 2).
  - La contrasena o el usuario del .env no coinciden con los del paso 6.

"Falta la variable ... en el archivo .env"
  - El archivo se llama .env.txt en vez de .env. Renombrarlo a .env.
  - Falta completar alguna variable (BD_CONTRASENA, SESION_SECRETO, etc.).

"El puerto 80 ya esta ocupado" (o 443)
  - Ya hay otro servidor corriendo en esa PC. Cerrarlo o cambiar PUERTO en
    el .env y abrir http://localhost:PUERTO.

La pagina carga pero sin datos
  - Falta cargar la base: npm run bd:crear.

"No se encontro el certificado ... Solo HTTP"
  - Es un aviso, no un error: significa que no se hizo el paso 7. La pagina
    igual anda por http://entheoswiki.localhost.

El navegador no abre entheoswiki.localhost
  - Falta la linea en el archivo hosts o INSTALAR.bat no tuvo permiso para
    agregarla. Ejecutar INSTALAR.bat como administrador (o ver el paso 7.1).

"Access denied for user 'entheos'"
  - El usuario de MySQL no existe o la contrasena no coincide. Repetir el
    paso 6 con la contrasena del .env.


----------------------------------------------------------------------------
LO QUE NO SE SUBE AL REPOSITORIO
----------------------------------------------------------------------------

  .env               contrasena de MySQL y secreto de sesion
  certificados/      clave privada del certificado
  node_modules/      se regenera con npm install
  web/subidas/       imagenes que suben los usuarios
  pdf-generados/     PDF generados

Cada computadora tiene su propio .env y sus propios certificados.
